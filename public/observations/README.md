# Observational previews

`alma-band8-2023.png` is Figure 1c from Dent et al. (2026), observed on 1 August 2023 under ALMA programme 2022.A.00026.S and downloaded from the paper's arXiv HTML source. The paper is licensed CC BY 4.0.

This image is used for editorial education and the README figure only. It is not a substitute for the calibrated FITS image or measurement set and must not be used as a quantitative, training, or prediction input.

`blink-test/` contains the corresponding rendered Bands 6, 7, and 8 panels
from Figure 1. They provide a compact, CC BY 4.0 demonstration set for the
browser's visual blink controls. Because the panels differ in frequency,
restoring beam, calibration uncertainty, and brightness scale, they are not a
time series and must not be used for quantitative differencing. The website
also distributes the three panels and their README as a single ZIP file.
