# Machine-learning research track

Neural work begins only after a relevant transparent baseline and a leakage-resistant evaluation design. Allowed targets are reconstruction, historical anomaly, epoch similarity, scenario-family compatibility, OOD score, and calibrated uncertainty. An `exploded/not exploded` target is forbidden.

The subdirectories reserve independently reviewable tracks for light curves, spectra, imaging, multimodal fusion, simulation-to-real work, calibration, experiments, and model cards. They intentionally contain no fabricated training results.
